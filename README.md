# 复健针言 · 内容作战台

面向康复与针灸医生的中文个人 IP 内容工作台。它把定位、选题、脚本、排期、发布记录和医学合规边界整合在一个静态网站中。

## 包含内容

- 一句话定位、三层价值与“疼痛六步管理法”
- 7 个固定栏目、72 个可筛选选题及拍摄提示
- 30—90 秒短视频脚本工坊与发布前自检
- 12 周 / 90 天执行计划和周任务进度
- 内容发布与数据复盘记录
- JSON / Markdown 导出和 JSON 恢复
- 医学表达、病例隐私与广告边界检查清单

## 数据说明

任务、脚本和发布记录使用浏览器 `localStorage` 保存在当前设备与浏览器中，不会上传到服务器。清理浏览器数据、更换浏览器或设备后不会自动同步，请定期使用“导出记录”备份。

## 本地查看

网站文件位于 `dist/`。可使用任意静态服务器打开，例如：

```bash
python -m http.server 4173 --directory dist
```
